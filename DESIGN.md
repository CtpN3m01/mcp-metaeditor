# MCP MetaEditor — Design Spec

## Overview

MCP server (Node.js/TypeScript) that connects Claude Code to MetaTrader 5's MetaEditor toolchain running on Linux via Wine. Enables a full workflow: write MQL5 code, compile, backtest, and iterate — all from the terminal.

## Architecture

```
┌─────────────┐       stdio        ┌──────────────────┐
│ Claude Code  │◄──────────────────►│  MCP Server      │
│  (cliente)   │   JSON-RPC        │  (Node.js/TS)    │
└─────────────┘                    └──────┬───────────┘
                                          │
                                ┌─────────┼─────────┐
                                │         │         │
                                ▼         ▼         ▼
                          Filesystem   Wine CLI   Log Parser
                          (MQL5/)     (metaeditor  (compile &
                                      64.exe)     backtest)
```

- **Transport**: stdio (standard for local MCPs with Claude Code)
- **Runtime**: Node.js with `@modelcontextprotocol/sdk`
- **Stateless**: Each tool call is independent
- **Config**: WINEPREFIX and MT5 paths via environment variables

### Key Paths

| Path | Value |
|------|-------|
| WINEPREFIX | `~/.mt5` |
| MT5 Dir | `~/.mt5/drive_c/Program Files/MetaTrader 5/` |
| MQL5 Dir | `~/.mt5/drive_c/Program Files/MetaTrader 5/MQL5/` |
| Compiler | `~/.mt5/drive_c/Program Files/MetaTrader 5/MetaEditor64.exe` |
| Terminal | `~/.mt5/drive_c/Program Files/MetaTrader 5/terminal64.exe` |

## Tools

### 1. `list_mql5_files`

List MQL5 source files by type.

- **Params**: `type` (experts | indicators | scripts | include | all), `pattern` (optional glob)
- **Returns**: Array of `{ path, size, modified }` relative to MQL5/
- **Scans**: `MQL5/Experts/`, `MQL5/Indicators/`, `MQL5/Scripts/`, `MQL5/Include/`

### 2. `read_mql5_file`

Read a MQL5 source file.

- **Params**: `path` (relative to MQL5/, e.g. `Experts/MyEA.mq5`)
- **Returns**: File content as string

### 3. `write_mql5_file`

Create or overwrite a MQL5 source file.

- **Params**: `path` (relative to MQL5/), `content` (full MQL5 source code)
- **Behavior**: Creates intermediate directories if needed
- **Returns**: Confirmation with absolute path written

### 4. `compile_mql5`

Compile a MQL5 file using MetaEditor CLI.

- **Params**: `path` (relative to MQL5/)
- **Executes**: `WINEPREFIX=~/.mt5 wine MetaEditor64.exe /compile:"MQL5/<path>" /log`
- **Returns**: Success/failure + parsed compilation log summary
- **Timeout**: 30 seconds

### 5. `get_compile_errors`

Read and parse the compilation log.

- **Params**: `path` (optional, defaults to last compiled file)
- **Returns**: Structured list of `{ line, column, type (error|warning), message }`
- **Note**: MetaEditor logs are UTF-16LE encoded; parser converts to UTF-8

### 6. `run_backtest`

Run a backtest via MT5 Strategy Tester.

- **Params**: `expert` (path to EA), `symbol`, `period` (M1, M5, M15, M30, H1, H4, D1, W1, MN1), `date_from`, `date_to`, `deposit` (default 10000), `leverage` (default "1:100")
- **Behavior**:
  1. Generates a `.ini` config file for the Strategy Tester
  2. Executes `WINEPREFIX=~/.mt5 wine terminal64.exe /config:test.ini`
  3. Polls the Tester results directory for new output files
- **Returns**: Confirmation that backtest was launched
- **Timeout**: 5 minutes for results to appear

### 7. `get_backtest_results`

Read and parse backtest results.

- **Params**: `expert` (EA name)
- **Returns**: Key metrics: `{ profit, drawdown, totalTrades, winRate, profitFactor, sharpeRatio, maxDrawdownPercent }`
- **Source**: Parses XML/HTML report generated by MT5 Tester

## Error Handling

- **Path validation**: All paths validated to stay within `MQL5/` — `../` traversal is rejected
- **UTF-16LE logs**: MetaEditor and MT5 generate UTF-16LE encoded logs. All log parsing converts to UTF-8 before returning.
- **Compiler timeout**: 30 second timeout on compilation. Returns error on timeout.
- **Backtest timeout**: 5 minute polling timeout for results. Returns error if no results appear.
- **Wine process**: If Wine/MT5 crashes, the error is captured from stderr and returned.
- **MT5 instance**: If MT5 is already running, backtest launches in that instance. If not, starts a new one.

## Project Structure

```
mcp-metaeditor/
├── src/
│   ├── index.ts          # Entry point, MCP server setup
│   ├── tools/
│   │   ├── files.ts      # list_mql5_files, read_mql5_file, write_mql5_file
│   │   ├── compile.ts    # compile_mql5, get_compile_errors
│   │   └── backtest.ts   # run_backtest, get_backtest_results
│   ├── utils/
│   │   ├── wine.ts       # Execute commands via Wine
│   │   ├── paths.ts      # Path resolution and validation
│   │   └── log-parser.ts # UTF-16LE log parser
│   └── config.ts         # Configuration (MT5 paths, WINEPREFIX)
├── package.json
├── tsconfig.json
└── .env.example
```

## Configuration

Environment variables (`.env`):

```
MT5_WINEPREFIX=~/.mt5
MT5_PATH=~/.mt5/drive_c/Program Files/MetaTrader 5
```

## Target Instruments

- Multiple brokers (broker-agnostic design)
- Primary focus: Synthetic indices (Crash, Boom, Step Index, etc. from Deriv)

## Tech Stack

- Node.js + TypeScript
- `@modelcontextprotocol/sdk` for MCP server
- `child_process` for Wine execution
- No database, no external dependencies beyond Wine + MT5
